Когда эта опция выключена, лишь зарегистрированные пользователи с соответствующим разрешением могут добавлять учетные записи новых пользователей . Включить поддержку графического интерфейса Имя переменной в файле конфигурации : configGuiMode Тип значения : String Возможные значения : да, нет, авто Значение по умолчанию : авто Эта опция определяет, будет ли RatioT Server выполнять отрисовку GUI (графического интерфейса пользователя). GUI включает: всплывающее окно программы в начале запуска, иконку в Системном трее и окна с сообщениями об ошибке. Когда эта опция выключена, отрисовка GUI осуществляться не будет. Папка хранения статистики Имя переменной в файле конфигурации: statisticsFolder Тип значения: String Возможные значения: Любой валидный путь папки Значение по умолчанию: statistics Абсолютный или относительный путь к папке, которая используется для хранения данных канала статистики. Номер порта клиента Имя переменной в конфигурационном файле: clientPort Тип значения : Integer Возможные значения: 1-65535 Значение по умолчанию: 6460 Эта опция определяет порт, на котором принимаются соединения клиентов.
